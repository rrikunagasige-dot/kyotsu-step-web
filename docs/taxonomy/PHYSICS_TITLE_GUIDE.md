# 物理・問題分類タイトル設計 V1

## 目的

共通テスト物理の題庫を、短く、同じ粒度で、問題を迷わず置けるタイトルに整理する。

この分類は「知識タグを全部見せる」ためのものではない。問題一覧で最初に選ぶ主題だけを表す。斜方投射、摩擦、直列・並列、ドップラー効果などの細目は下位タグとして保持し、トップカードには上げない。

## 良いタイトルの条件

1. **短い** — 原則8文字以内。説明文ではなく名詞で置く。
2. **縦に揃う** — 同じ画面で「力学」と「斜方投射」を並べない。カードは章〜大単元程度の同一粒度にする。
3. **主題が一つ** — 解法、難易度、問題形式をタイトルに混ぜない。
4. **重なりを小さくする** — 1問につきprimary topicを1つ持つ。複合問題の副要素はknowledgeTagsへ置く。
5. **教科書に依存しすぎない** — 特定出版社の章名をそのままコピーせず、複数教科書・学習指導要領で通用する一般名へ正規化する。
6. **増えても壊れない** — 問題数が0でもカテゴリを残し、題庫の不足を可視化する。
7. **分類できない問題を隠さない** — 未分類数を計測し、taxonomy漏れを検知する。

## 下位タグへ置く例

| primary title | 下位タグの例 |
|---|---|
| 運動 | 等速直線運動、速度–時間グラフ、水平投射、斜方投射 |
| 力 | 運動方程式、摩擦、張力、浮力 |
| エネルギー | 仕事、運動エネルギー、位置エネルギー、力学的エネルギー保存 |
| 運動量 | 力積、衝突、反発係数 |
| 円運動・万有引力 | 単振動、ケプラー、人工衛星 |
| 電流 | オームの法則、直列・並列、電力 |
| 磁場 | ローレンツ力、電流が磁場から受ける力 |
| 電磁誘導 | 誘導起電力、交流、電磁波 |
| 量子 | 光電効果、物質波、電子 |
| 原子核 | 放射線、核反応、核エネルギー |

## 根拠にした範囲

- 文部科学省「高等学校学習指導要領」物理：様々な運動、波、電気と磁気、原子などの内容構成
- 文部科学省「高等学校学習指導要領解説 理科編 理数編」
- 数研出版「改訂版 物理」章構成：平面内の運動、剛体、運動量、円運動と万有引力、気体、波、音、光、電場、電流、磁場、電磁誘導と電磁波、電子と光、原子と原子核
- 大学入試センター 共通テスト問題評価・分析資料：物理では複数領域を横断して出題されるため、年度別の出題比率ではなく学習範囲そのものをtaxonomyの基準にする

## 実装ルール

- UIのカードIDは `PhysicsTopicId` をcanonical valueとする。
- 現行Question schemaは変更せず、既存 `taxonomy.minorUnit` をalias tableでcanonical topicへ正規化する。
- 新規問題では可能ならcanonical topic IDを `minorUnit` に直接使う。
- skillTag / knowledgeTags をprimary titleの代わりにしない。
- 題庫画面では0件カテゴリも灰色表示する。
- 1件以上のカードはクリックするとそのtopicだけに絞ったpractice setupへ遷移する。
