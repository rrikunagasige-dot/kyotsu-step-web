# Correction Review Link Lesson

Updated: 2026-10-19
Authority: W-GOV-008/P-001; normative procedure governance/WORK_SYSTEM.md §12A.

A usable correction handoff means one tap opens the **actual changed app interaction** at the exact question/stage and tested PR head. User confirmation is a product test.

- Never ask a user to interpret a PR, branch, ZIP, artifact or start Codespaces.
- Give specific before/after expectations, a tiny checklist and PASS / 要修正.
- Verify link, commit/revision, mobile and desktop, wrong/correct gating and progress isolation first.
- No real preview → USER-REVIEW-NOT-READY, no acceptance request. Old production is not a PR preview.
- Preview publication, main merge and Pages release each preserve separate authorization.

See docs/MASTER_APP_LESSONS.md §54. The earlier PR fallback was deliberately superseded; historical PRs remain evidence.
