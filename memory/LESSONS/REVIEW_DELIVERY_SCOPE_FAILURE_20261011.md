# Lesson — Review Delivery Is An Acceptance Gate
Date: 2026-10-11
Work: W-GOV-008, W-MATH-002
A UI task is not user-review-ready when only a PR, zip or local-launch script is available. Specify direct running app URL delivery before implementation, record permission and provider dependencies, and verify that the URL serves the intended commit with browser/asset evidence. Keep CI success, deployment success and human acceptance independent. Never assign local environment setup to the user without explicit consent. If the review artifact cannot be provided within scope, mark BLOCKED (PREVIEW_MISSING) and propose an authorized solution rather than improvising another deliverable.
