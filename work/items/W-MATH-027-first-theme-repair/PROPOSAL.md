# Accepted design applied to the first theme

Each inserted node records its original target, preceding explanation, explicit formula stem,
answer, three authored distractors, targeted hint and optional bridge to the next operation.
The renderer inserts each node exactly once before its target; missing anchors are errors.
Mathematical answers are authored, not inferred by rendering code.

N07–N14 and NE02 JSON content is protected by baseline hashes. Catalog membership changes only.
Old question IDs and answers remain stable. New revision migration retains old answers and archives
previous revision completion; new decision IDs remain unanswered. N01 stays revision2.

Display uses explicit authored stage anchors, retains every readingFlow block in original order,
and provides only earlier prerequisite blocks. Completed stages expand on demand. Shared math wrapping
is enabled only for these seven units, including options and resolved equations.
