# 教材制作ワークフロー：紹介用資料

`workflow_roles.html` をブラウザで開くと、全体・共通・作成・修正・機械学習の5つの図を切り替えられます。外部通信は不要です。印刷すると、選んだ図だけを共有できます。

- `overview.svg`：元の火柴図を、AI・CODE・USERの担当付きで展開した全体図。
- `common.svg` / `creation.svg` / `correction.svg` / `learning.svg`：各工程の担当と成果物を3列で記載。
- `RESPONSIBILITIES.md`：同じ内容の表。
- `overview.mmd`：編集用Mermaid source。
- `ROLE_MAP.json`：実工程との対応。作成・修正の全18工程を重複なく収録。

## 紹介するときの説明

私たちの入口は「作成」と「修正」の二つです。AIが原資料の意味、完全解法、教える順序、文章、穴、図、実装を作り、コードが版・依存・採点・式の接続・描画・進捗などを検査します。ユーザーは具体案を承認し、既存アプリに反映された実物を評価します。コード検査だけで教育的な良し悪しを決めず、AIの自己評価だけでも合格にしません。

評価は対象版と観点を残して蓄積します。否定的な指摘は修正へ、肯定評価は事例・学習へ渡します。モデルは類似事例や候補順位の助言用であり、数学の正しさや公開可否、ユーザー承認を代行しません。

**CODEは「プログラムを実行する担当」です。AIがコードを書く仕事とは区別します。** また、同じAIによる見直しを、独立した別AI監査とは呼びません。

## 今回の実データ

新しい肯定例は、公開版N07全体の受入1件です。元の否定例を消したり、六つの独立した肯定例へ増やしたりしていません。評価済み10件（否定7・肯定3）。既存の配置判定headは再fitしましたが、新しい「N07全体の受入」のheadは正負不足で学習対象外です。独立した教材familyは2つで、未知教材への汎化精度は未評価。モデルはOFFLINE_ONLYのままです。

図は責任分担を説明するものです。図に工程があることを、その工程が実行済みである根拠にはしません。

学習の実装は、固定した多言語encoderで実教材をvector化し、観点別のLogisticRegression headをfitする方式です。ChatGPT本体や事前学習encoderの重みを再学習したものではありません。入力全tokenの処理記録を保持しています。
